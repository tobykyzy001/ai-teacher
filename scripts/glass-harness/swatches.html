玻璃材质对照 · old / new

old/* = git show HEAD 冻结的配方； new/* = 材质系统 v5 的 --mat-*（直接读 /src/style.css）。 每个格子的背景逐像素相同（各自画同一张底），所以横向差异只可能来自材质； 每带第一个是"裸底"对照。
材质系统 v5 把控件分成两类：new/ctl-* = 页面按钮（纯灰 --ctl-*，不做玻璃，因为背后没有内容可透）； new/glass-* = 浮在内容之上的控件（侧栏收放钮/翻章箭头/Aa 钮，才用 --mat-* 玻璃）。
